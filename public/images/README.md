## Installation
1. Unzip this package.
2. Copy the `01-farm-projects` and `02-funding-and-investment` folders into your frontend's `public/images/agribridge/` directory.
3. Reference images in React with paths such as:
   `<img src="/images/agribridge/01-farm-projects/green-paddy-field.jpg" alt="Green paddy field" />`
4. Keep existing CSS, routes, forms, APIs and business logic unchanged. Add images incrementally and verify each page.
5. Use the investment images only in funding, sustainability, or analytics areas—not as crop photos.

## Important
Some supplied photos may include stock-photo watermarks or source branding. Confirm usage rights and replace watermarked images before public/commercial deployment. These assets are visual content only; this package does not modify your application source code.
